# mGBA Pocket Shelf 测试版

这是接入 mGBA 的 C / OpenGL ES 原生卡带架，不依赖浏览器、Three.js 或网络服务。

## 安装

1. 把安装包中「SD卡文件」里的 `switch/mgba-pocket-shelf` 文件夹复制到 SD 卡的 `/switch/`。
2. 保留原来的 `/switch/mgba/mgba.nro`。这是独立测试入口，两者可以并存。
3. 游戏沿用 `/roms`，会递归扫描其中的 `.gba / .agb / .gb / .gbc / .sgb`。不需要挪动现有游戏。
4. 按住 R 打开一个已安装游戏，进入完整内存模式的 hbmenu，选择 **mGBA Pocket Shelf**。首次测试请用已有的免费自制游戏。

## 操作

| 按键 | 卡带架里的功能 |
| --- | --- |
| 手指在卡带架左右滑动 | 跟手浏览，松手惯性吸附；滑动不会启动游戏 |
| 十字键左右 / 左摇杆 | 选择游戏；按住可连续选择 |
| A | 拿起卡带 → 翻到机背 → 插入 → 转回正面 → 开机启动游戏 |
| B | 取消插卡并放回 |
| X | 重新扫描游戏和封面 |
| Y | 查看机背 / 正面 |
| ZR | 开关减少动画 |
| − | 打开 mGBA 原版文件浏览器 |
| ＋ | 退出卡带架 |

进入游戏后沿用 mGBA 的按键：A/B 对应 A/B，＋/− 对应 Start/Select，L/R 对应 L/R。**X 打开 mGBA 暂停菜单，选「Exit game」回到卡带架**；不要把游戏里的 ＋ 当退出键。若以前自定义过映射，沿用原来的配置。

掌机触摸可直接在卡带架左右滑动浏览，松手后会对齐选中的卡带；轻点侧边卡带选择，点中间卡带或底部 A 按钮启动。滑动、竖向移动、取消触摸和多指操作不会被当成一次启动点击。原生版暂未实现网页原型的自由拖拽、音效和外壳换色。

## 封面和存档

- 原生版读取同名 **PNG**：例如 `Anguna.gba` 对应 `Anguna.png`，或该目录 `covers/Anguna.png`。
- PNG 最大输入尺寸 2048 × 2048，上传 GPU 前会缩至最长边 512；只缓存附近五张封面。JPEG、自动联网匹配封面暂未接入原生版。
- 没有封面会生成带游戏名的标签；三个示例自制游戏有本项目自绘标签。安装包不含游戏 ROM。
- 游戏由 mGBA 本来的加载、存档和暂停流程运行；仍使用现有 mGBA 配置及存档路径。
- 修改选项时仍会更新 mGBA 的 `switch` 配置，例如最近游戏、最近目录和减少动画。安装包不改 ROM 或存档。

高级选项可以放进现有 mGBA 的 `switch` 配置节：`pocketShelfRoms=sdmc:/roms` 指定根目录，`pocketShelfReducedMotion=1` 减少动画。通常无需改动。

## 今晚验收

依次检查：卡带架能否打开 → 左右/A/B 是否正确 → 游戏画面声音是否正常 → X 菜单退出后是否回到卡带架 → 再打开第二个游戏 → 存档能否继续读取 → HOME/睡眠恢复及底座切换是否正常。

已完成：原生 Mac GPU 渲染、真实 ROM 运行、启动/返回、目录和动画测试、Switch 交叉编译与 NRO 内嵌资源校验。**2026-10-27 首轮 Switch 实机测试已确认原生卡带架能正常显示，启动日志也记录了渲染器初始化成功。音频、按键、存档连续性、睡眠恢复与底座切换继续验收。**

如卡带架无法启动，会显示具体错误；诊断日志保存在 `/mGBA/pocket-shelf.log`。按 A/B 可进入原版文件浏览器，按 ＋ 退出。保留原版入口继续使用；不要覆盖原版 NRO。排查时记录报错文字、启动方式（R 完整模式或相册）和系统/Atmosphère 版本即可。
